# practica1barrosso

Proyecto base de la API backend para la historia HU-SEC-001.

## Requisitos

- Java 21
- Maven 3.9 o posterior

## Ejecutar

```powershell
mvn spring-boot:run
```

## Probar

```powershell
mvn test
```

Esta primera etapa contiene únicamente el esqueleto inicial de Spring Boot. No incluye todavía autenticación, Spring Security ni configuración TLS/SSL.
